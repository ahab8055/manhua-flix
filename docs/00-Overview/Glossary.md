# Glossary

- **Manhua / manhwa** — Chinese / Korean comics; here delivered as animated recap videos per chapter.
- **Channel** — creator page owning manhuas; users subscribe, pin, set notifications.
- **Uploader** — role managing manhuas of channels they own (`channel_owners`).
- **Chapter / Episode** — backend "chapter" = mobile "Episode" screen; one Dailymotion video.
- **Rank** — F, E, D, C, B, A, S, SS, SSS by points.
- **SSV** — AdMob server-side verification of rewarded ads.
- **Colab job / upload job** — pipeline job row (`colab_jobs`), now run on Kaggle.
- **Release topic** — FCM topic `new_releases`.
- **MOC** — Map of Content (index note) in this vault.
